# Concept

สมการสองสมการเรียกว่า “สมมูลกัน” เมื่อมีเซตคำตอบเดียวกัน

# Intuition

เครื่องหมายเท่ากับหมายถึงค่าทางซ้ายและขวาเท่ากันอยู่แล้ว ดังนั้นถ้าเราทำการดำเนินการเดียวกันกับทั้งสองข้าง เช่น บวก ลบ คูณ หรือหารด้วยจำนวนที่ไม่เป็นศูนย์ ความสมดุลของสมการจะยังคงอยู่

# Example

จาก

\[
x + 5 = 12
\]

ลบ 5 ทั้งสองข้าง

\[
x + 5 - 5 = 12 - 5
\]

จึงได้

\[
x = 7
\]

# Common Mistakes

- จำว่า “ย้ายข้างแล้วเปลี่ยนเครื่องหมาย” โดยไม่เข้าใจว่าจริง ๆ คือการทำ inverse operation กับทั้งสองข้าง
- หารทั้งสองข้างด้วยศูนย์

# Retrieval Summary

ใช้เมื่อผู้เรียนถามว่าเหตุใดการย้ายข้างจึงเปลี่ยนเครื่องหมาย หรือเหตุใดการทำสิ่งเดียวกันกับทั้งสองข้างของสมการจึงไม่เปลี่ยนคำตอบ
